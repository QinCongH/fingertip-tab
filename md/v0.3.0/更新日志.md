# 指尖乐谱 (Fingertip Tabs) v0.3.0 更新日志

> 发布日期：2026-09-15  
> 版本代号：**v0.3.0** —— Guitar Pro 深度支持与局域网跨端共享

---

## 🌟 版本亮点概览

v0.3.0 带来两大里程碑级核心演进：
1. **全套 Guitar Pro（GP3/4/5/GPX/GP）曲谱原生解析、专业级练习器与播放引擎**：在纯本地、不联网的前提下，对标行业标杆体验，支持六线/五线谱渲染、多音轨混音、小节循环、节拍器/预备拍、动态宽度自适应拖拽与舒适区自动滚屏。
2. **局域网共享乐谱库与移动端协同**：无需部署外部服务器或安装移动 App，同一 Wi-Fi 下一键扫码即可在手机浏览器秒开整套曲谱库，支持搜索检索、原汁原味的 GP 谱播放与图片谱大图手势缩放/自动滚屏。

---

## 🎸 核心功能详解

### 1. Guitar Pro 完整支持与专业播放器

- **多格式本地导入**：
  - 支持 `.gp3`、`.gp4`、`.gp5`、`.gpx` 与 `.gp` 全格式 Guitar Pro 文件导入。
  - 导入对话框支持「图片谱 / GP 曲谱」类型分流，支持从文件读取或系统拖拽；文件本地落盘于独立 `Resources/GPFiles/` 目录。
  - 导入与解析全流程在本地执行，严守隐私安全，无任何外部数据上传。
- **高保真谱面渲染（基于 AlphaTab）**：
  - 默认自适应铺满可视区域，支持五线谱、六线谱、和弦名称动态显隐切换。
  - 支持谱面缩放（20% ~ 200%）、平滑跟随滚动与连续跟随滚动。
  - 左右两侧边缘设有隐式拖拽拉伸手柄（鼠标悬浮 32px 热区淡入），支持对称拖拽调节谱面宽度、双击复位自适应及 `Ctrl + 滚轮` 调节。
- **专业伴奏练习器**：
  - **精准小节高亮**：提供小节红色半透明背景高亮与拍点光标，当前演奏进度一目了然。
  - **变速练习**：0.25x ~ 2.0x 无级变速与快捷预设倍速。
  - **小节循环练习（AB Loop）**：支持可视化划选小节或输入起止小节循环练习，配备独立小节循环悬浮面板。
  - **多音轨混音面板**：支持音轨列表查看、Solo（独奏）、Mute（静音）、音量及声像微调。
  - **节拍辅助**：支持独立节拍器开关、音量调节与预备拍（Count-in，1~2 小节提前找准起拍）。
  - **状态持久化**：每首 GP 谱均自动记忆用户上次调节的速度、音轨状态与谱面配置，重新打开秒级恢复。

---

### 2. 局域网共享与移动端跨端看谱体验

- **首页整库共享入口与状态联动**：
  - 首页顶栏「设置」左侧新增局域网共享二维码图标。
  - 点击弹出共享弹窗，自动以非阻塞后台机制开启轻量 Axum 局域网共享服务，展示专属访问二维码与 URL，首页图标同步呈现高亮状态。
  - 弹窗内支持一键复制访问链接或关闭共享；关闭后服务立即停止且 Token 失效，首页二维码图标恢复普通状态，防止未授权访问。
- **移动端单页一体化体验（无需 App）**：
  - 手机扫码后进入「顶部实时搜索框 + 底部所有曲谱列表」视图，支持按曲谱名/歌手实时检索，带有 GP 红色徽标与图片谱页数徽标。
  - 点击任意曲谱秒开详情页，左上角常驻「返回」按钮随时返回列表。
  - **移动端 GP 查看**：内置 GBK/UTF-8 自动识别（彻底杜绝老曲谱中文乱码），移动端自适应 40% 缩放，支持触控播放、时间拖拽、五六线谱切换与演奏行视口舒适区平滑自动跟随。
  - **移动端图片谱**：连续分页瀑布流、悬浮平滑自动滚动栏（10~300 px/s 调速），支持点击进入 Lightbox 全屏预览、双指捏合缩放、双击放大与左右滑动手势翻页。

---

### 3. 查看器通用交互与图片谱增强

- **图片翻页模式边缘拉伸**：
  - 图片谱单页翻页模式（`fixed`）同样加入左右边缘对称拉伸把手、`Ctrl + 滚轮` 缩放以及双击复位。
  - 手柄交互与 GP 谱保持统一的隐式设计：平时透明无感，鼠标靠近边缘 32px 热区时平滑显现，绝不遮挡乐谱内容。
- **多态查看与快捷切换**：
  - 查看器针对 GP 谱与图片谱自动切换对应工具栏与底栏面板，兼顾键盘快捷键、全屏沉浸演奏与 AI 动作控制。

---

### 4. 存储与系统层优化

- **数据库架构平滑升级**：
  - 数据库自动迁移，在 `songs` 表中扩充 `format`（`image` / `gp`）与 `file_type` 字段，向下无缝兼容原有图片谱库。
  - 扩展级联删除逻辑，删除 GP 谱时自动同步清理 `Resources/GPFiles/` 中的源文件。
  - 曲谱库备份与恢复升级为全量 ZIP 打包，完整包含数据库、图片页、缩略图以及所有 GP 乐谱文件。
- **网络与安全架构**：
  - 局域网共享采用随机会话 Token 隔离，本地资源仅允许通过白名单格式在应用库目录内读取，杜绝路径穿越。
  - 自动识别并优先绑定 192.168.x.x / 10.x.x.x 局域网物理网卡 IPv4 地址，规避虚拟网卡/Docker 地址无法扫码的问题。

## 🛠️ 问题修复与细节打磨

1. **修复**：老版本 GP 谱由于采用 GBK 编码在浏览器端解码导致歌名、歌手与乐谱提示乱码的问题。
2. **修复**：全屏查看与翻页模式下拖拽拉手长期驻留对视线造成干扰的问题，改为边缘热区悬浮淡入。
3. **修复**：Axum 在多网卡与移动热点环境下绑定无效私有 IP 的问题，重构了跨平台物理 LAN IPv4 探测算法。
4. **优化**：小节循环悬浮窗背景透明度与毛玻璃滤镜优化，提升弱光看谱环境下的视觉舒适度。
5. **优化**：AlphaTab 离线字体库与音色库本地打包分发，即使在断网演出现场也能稳定播放。
