# 指尖乐谱 v0.3.0 —— GP 曲谱支持功能需求文档

> 依据 `详细需求文档.md`（TabPilot 参考方案）、`看谱功能支持gp.md`（混合曲谱方案）与当前代码实现整理。
> 目标版本：**v0.3.0**。交付原则：本地优先、非侵入扩展、复用既有基础设施。

---

## 1. 背景与目标

### 1.1 现状
指尖乐谱（fingertip-tab）是基于 **Tauri v2 + Vue 3 + TypeScript + Vuetify + SQLite** 的本地曲谱管理桌面应用，当前已实现：

- 曲谱库：分组侧栏、卡片网格、搜索、多页图片导入（文件/截图/剪贴板）、拖拽排序、OCR 辅助标题。
- 图片看谱器：翻页 / 滚动 / 双页三种模式、缩放（适应宽/高/实际）、自动滚动（px/s 或 BPM）、全屏悬浮工具栏、AI 摇头翻页、背景色、快捷键自定义。
- 存储：`Resources/Images/{uuid}.{ext}` + `Resources/Thumbnails/` 缩略图 + SQLite（`songs / pages / collections / song_collections`）+ `settings.json`，支持库迁移与 ZIP 备份/恢复。

### 1.2 本期目标
在保持图片曲谱能力不变的前提下，**原生支持 Guitar Pro 曲谱（`.gp3/.gp4/.gp5/.gpx/.gp`）**，提供与 TabPilot 对标的"看谱 + 练习"体验：

1. 导入时按类型分流（图片 / GP），文件分别落盘到 `Resources/Images/` 与 `Resources/GPFiles/`。
2. 查看页按曲谱类型多态渲染：图片查看器沿用现有实现，GP 曲谱使用 **AlphaTab** 引擎渲染与播放。
3. 提供播放跟随、滚动、速度、音轨（Mute/Solo/音量/声像）、循环小节、节拍器/预备拍等核心练习能力。
4. 全流程本地解析，文件不上传、不联网；练习状态（循环片段收藏、上次速度等）仅存本机。

### 1.3 非目标（本期不做）
- 谱面编辑、制谱、转调、打印。
- 练习统计报表、渐进变速训练器、计时器、MIDI 导出（列入 v0.4.0 候选）。
- Pro/商业化倍速档位与付费引导（开源本地工具，全部速度直接可用）。
- 埋点上报（纯本地产品，无上报通道；如后续接入统计平台再补）。

## 3. 数据模型与存储设计

### 3.1 数据库变更（最小侵入）

当前 `songs` 表已有 `file_type`（图片扩展名）与 `uuid`（封面/首文件 uuid）。为区分渲染路径，新增 `format` 字段：

```sql
ALTER TABLE songs ADD COLUMN format TEXT NOT NULL DEFAULT 'image';
-- 'image'：图片曲谱（多页）；'gp'：Guitar Pro 曲谱（单文件）
```

迁移策略：现有 `init.sql` 为 `CREATE TABLE IF NOT EXISTS`，需在 `init_db`（`src-tauri/src/db/connection.rs`）建表后追加幂等迁移：

```rust
// 已存在库补列；新库由 init.sql 直接含该列（二选一，保持幂等）
sqlx::query("ALTER TABLE songs ADD COLUMN format TEXT NOT NULL DEFAULT 'image'")
    .execute(&pool).await.ok(); // 忽略 duplicate column 错误
```

- `pages` 表**不用于** GP 曲谱（GP 为单文件，无分页概念）；GP 曲谱 `pages` 为空，前端判断 `format === 'gp'` 后走 GP 路径。
- GP 曲谱的 `uuid` 即其 GP 文件名主体，`file_type` 存扩展名（如 `gp5`），与图片谱同构，减少模型分叉。
- `SongDto` 增加 `format: string` 字段（`src/lib/tauri.ts` + `src-tauri/src/db/models.rs`），默认 `'image'`。

### 3.2 文件存储

```text
{库目录}/
├── FingertipTabs.db
├── settings.json
└── Resources/
    ├── Images/          # 图片谱分页（现有）
    ├── Thumbnails/      # 图片缩略图（现有）
    └── GPFiles/         # 新增：{uuid}.gp3/.gp4/.gp5/.gpx/.gp
```

- `ensure_library_ready`（`src-tauri/src/commands/settings.rs`）需补建 `Resources/GPFiles`。
- `migrate_library` / `backup_library` / `restore_library` 操作以 `Resources` 目录为单位，GPFiles 随目录自动覆盖，无需单独处理，但需在验收中验证。
- `delete_song` 需增加 GP 文件清理分支：`Resources/GPFiles/{uuid}.{file_type}`。
- GP 谱**不生成图片缩略图**；卡片封面用类型图标或 AlphaTab 首屏离屏渲染（可选优化，P2）。

### 3.3 练习状态持久化

`settings.json` 的 `AppSettings` 新增 `gp_player` 段（全局默认）与按曲谱记忆（可选 `songs` 表新增 `player_state TEXT` JSON 列，或存 `settings.json` 的 map）。推荐方案：

```ts
// AppSettings 增加
gp_player: {
  zoom: number;            // 默认缩放 0.8–1.5
  show_standard_notation: boolean;  // 五线谱，默认 true
  show_chord_names: boolean;        // 和弦名，默认 true
  count_in_beats: 0 | 1 | 2 | 4;    // 预备拍，默认 0
  scroll_mode: "continuous" | "smooth" | "off";
  metronome_volume: number;  // 0–100
}
```

按曲谱的练习状态（速度、循环区间、音轨混音）建议存入 `songs.player_state`（JSON 文本列，默认 `NULL`），避免 settings.json 随曲谱数膨胀；该列同样用幂等 `ALTER TABLE` 迁移。

## 4. 导入功能需求

### 4.1 交互流程（改造 `ImportDialog.vue`）

1. 点击"导入"打开对话框，顶部新增**曲谱类型**分段选择器：`图片曲谱` / `Guitar Pro 曲谱`。
2. 默认类型取上次成功导入的类型（存 `settings.json` 的 `import.last_format`），首次默认"图片曲谱"。
3. 选择"Guitar Pro 曲谱"后：
   - 分页列表区替换为**单文件选择**：`open({ multiple: false, filters: [{ name: "Guitar Pro", extensions: ["gp3","gp4","gp5","gpx","gp"] }] })`。
   - 禁用截图录入、剪贴板粘贴、分页排序、OCR。
   - 标题默认填充文件名（去扩展名），其余元数据（艺术家/专辑/调弦/BPM/标签/分组）照常可填；AlphaTab 解析成功后可回填标题/艺术家（若元数据为空）。
4. 保存：调用扩展后的 `import_songs`（或新增 `import_gp_song`），携带 `format` 与文件路径。

### 4.2 后端接口

推荐新增独立命令，避免污染图片多页逻辑：

```rust
#[tauri::command]
pub async fn import_gp_song(
    app: AppHandle,
    state: tauri::State<'_, AppState>,
    path: String,
    meta: SongMetaInput,
    collection_ids: Vec<i64>,
) -> Result<SongDto>
```

- 校验：扩展名白名单 `["gp3","gp4","gp5","gpx","gp"]`（`src-tauri/src/utils/file.rs` 新增 `GP_EXTS`）；文件存在且非空；大小上限建议 50MB（超过提示但可放行或拒绝，见异常表）。
- 落盘：`Resources/GPFiles/{uuid}.{ext}`（复制，不移动原文件）。
- 入库：`format='gp'`、`uuid`、`file_type=ext`，不写 `pages`；`songs.file_type` 保留扩展名用于拼路径。

### 4.3 读取接口

AlphaTab 需要文件二进制。新增命令：

```rust
#[tauri::command]
pub async fn read_file_bytes(path: String) -> Result<Vec<u8>>  // 或 base64
```

前端拿到字节后 `new Uint8Array(bytes)` 喂给 `AlphaTabApi.load()`。路径白名单限制在库目录 `Resources/GPFiles` 内，防目录穿越。

## 5. 查看功能需求（核心）

### 5.1 多态渲染

`ViewerView.vue` 根据 `song.format` 分流：

```vue
<component :is="song?.format === 'gp' ? GpViewer : ImageViewer" :song="song" />
```

- 现有 ViewerView 中与图片强绑定的部分（pages、缩放模式、双页、AI 摇头翻页、自动滚动）抽为 `ImageViewer` 语义层；顶栏保留公共操作（返回、标题、全屏、背景色）。
- **GP 模式下禁用**：翻页/双页/滚动三模式切换器、px/s 自动滚动、AI 摇头翻页、图片缩放项（替换为谱面缩放）、分页指示器。

### 5.2 GpViewer 组件（新增 `src/components/GpViewer.vue`）

技术选型：[`@coderline/alphatab`](https://www.alphatab.net/)（MIT 许可，支持 .gp3–.gp5/.gpx/.gp，自带合成器音源可播放，纯本地）。需将 `alphaTab` 的 `font`/`soundfont` 资源放入 `public/` 或随包分发，配置 `core.fontDirectory` 与 `player.soundFontSource`。

#### F03 谱面渲染
- 同时渲染六线谱（Tab）与五线谱（Standard），默认开启；可由设置关闭五线谱。
- 保留演奏记号（推弦、滑音、击勾弦、泛音、制音等，AlphaTab 原生支持）。
- 多音轨：默认渲染全部音轨（并列或下拉选择显示某轨，参考 AlphaTab `tracks` 配置；推荐"全部音轨并列渲染"与图片谱"默认全展开"心智一致）。
- 渲染状态：加载中骨架/进度提示；失败时展示错误面板（见 §7 异常）。

#### F04 播放控制
- 播放/暂停/停止按钮；进度条（`playerPosition`）可拖拽 seek；时间码 `mm:ss / mm:ss`。
- 播放跟随：AlphaTab 的 `playerPositionChanged` + `beatCursor` 高亮当前拍/小节（内置游标样式，主色建议沿用应用主题色，可定制 CSS）。
- 循环区间在进度条上以高亮区段标识。

#### F05 速度控制
- 滑块 0.25x–2.0x（步进 0.05）+ 档位按钮：0.5x / 0.75x / 1x / 1.25x / 1.5x / 2x。
- `api.playbackSpeed = value`，实时生效；选择值写入 `player_state`，重开恢复。

#### F06 音轨混音
- 左/右侧抽屉列出全部音轨（编号 + 名称 + 乐器），每轨：Mute、Solo、音量滑块（0–100）、声像滑块（-50–+50）。
- 互斥规则：开 Solo 的轨使其余轨静音（多轨 Solo 并存）；Mute 与 Solo 同轨互斥。
- 状态写入 `player_state`。

#### F07 循环小节
- 输入框/选择器设置开始、结束小节（1–总小节数）；校验 `end >= start`，超出总数自动截断并 toast 提示。
- 开启后 `api.playbackRange = { startTick, endTick }` + `isLooping = true`；提供"清除循环"。
- 谱面点击选区设置循环（AlphaTab 支持 range selection）列为 P1 增强。

#### F08 滚动与布局
- 滚动模式映射：`连续跟随`（`scrollMode: continuous`）、`平滑跟随`（`smooth`）、`关闭滚动`（`offScreen` 手动）。`自动翻页`模式在 GP 上暂缓（AlphaTab `page` 布局 + 手动滚动近似，列入 v0.4.0）。
- 谱面缩放：0.5x–2.0x 滑块（`settings.display.scale`）。
- 全屏：复用现有 F11/Esc 全屏与悬浮工具栏框架；GP 模式下悬浮栏内容为播放控制。

#### F09 节拍器与预备拍
- 节拍器开关：`api.metronomeVolume`（0 关闭）+ 音量滑块；与播放独立。
- Count-in：`api.countInVolume` + 拍数来自设置 `count_in_beats`（0/1/2/4 拍）。

#### F10 练习状态持久化
- 播放停止或离开页面时，将 `{ speed, loop:{start,end,enabled}, tracks:[{mute,solo,volume,pan}], scrollMode, zoom }` 写入 `songs.player_state`；打开时恢复。
- 后端新增 `update_player_state(id, state_json)` 命令（或并入 `update_song`）。

### 5.3 曲谱库适配（`LibraryView.vue` / `SongCard.vue`）

- GP 卡片：无缩略图时显示类型徽标（如 `mdi-music-note` + "GP"角标），或调用 AlphaTab 离屏渲染首屏缩略图（P2）。
- 列表支持按 `format` 过滤（ chips：全部 / 图片 / GP ），P1。
- `EditSongDialog`：GP 谱隐藏"分页管理"入口；元数据编辑保留。

## 7. 异常与边界

| 场景 | 处理 |
| :--- | :--- |
| 扩展名不在白名单 | 导入对话框即过滤；后端二次校验，报"不支持的格式：.xxx（支持 gp3/gp4/gp5/gpx/gp）" |
| 文件不存在 / 已移动 | `import_gp_song` 返回"文件不存在：path"；查看页 `read_file_bytes` 失败时显示"文件缺失，请检查库目录"并提供重新定位入口（P1） |
| 文件损坏/无法解析 | AlphaTab `error` 事件捕获 → 错误面板：提示文件损坏、建议用 Guitar Pro 重新导出；提供"重新导入""反馈问题"按钮 |
| 文件过大（>50MB） | 导入时提示"文件较大（N MB），加载可能较慢"，不阻断；>200MB 拒绝 |
| GP 谱调用图片接口 | `set_song_pages` / `add_pages_to_song` 对 `format='gp'` 返回"GP 曲谱不支持分页管理" |
| 空 `pages` 的图片谱 | 与现状一致（不应出现，导入已保证至少一页） |
| 旧库升级 | `format` 列默认 'image'，老数据零迁移成本 |
| 备份/恢复 | `backup_library` 已打包整个库目录，GPFiles 自动包含；恢复后校验文件存在性 |

## 8. 技术实现要点

### 8.1 依赖与资源
- 新增依赖：`@coderline/alphatab`（npm）。构建时将 `node_modules/@coderline/alphatab/dist/font/*` 与默认 soundfont 拷贝至 `public/alphatab/`（或 `vite` 静态资源），Tauri 打包进 `resources`。
- AlphaTab 需要 worker：`settings.core.useWorkers = true`（Vite 下用 `alphaTab.worker.url` 或 `?worker` 导入方式，按 AlphaTab 1.3+ 文档适配 Vite/Tauri CSP）。
- CSP：soundfont 解码用 WebAudio，`tauri.conf.json` 的 CSP 需允许 `blob:` worker 与 `data:`/`blob:` media。

### 8.2 关键文件改动清单

| 层 | 文件 | 改动 |
| :--- | :--- | :--- |
| DB | `migrations/init.sql` | `songs` 加 `format`、`player_state` 列（新库） |
| DB | `db/connection.rs` | 幂等 `ALTER TABLE` 迁移 |
| Model | `db/models.rs` | `SongDto` 加 `format` |
| Cmd | `commands/tab.rs` | `import_gp_song`、`read_file_bytes`、`update_player_state`；`delete_song` 清理 GPFiles |
| Cmd | `commands/settings.rs` | `ensure_library_ready` 建 `GPFiles`；`migrate/backup` 验证 |
| Util | `utils/file.rs` | `GP_EXTS` 白名单 |
| 前端类型 | `lib/tauri.ts` | `format`、`gp_player` 设置段、新 API 封装 |
| 组件 | `components/ImportDialog.vue` | 类型选择器 + GP 单文件分支 |
| 组件 | `components/GpViewer.vue` | 新增：AlphaTab 封装 |
| 页面 | `pages/ViewerView.vue` | 多态分流；图片逻辑收口 |
| 页面 | `pages/LibraryView.vue`、`components/SongCard.vue` | GP 徽标/封面、过滤 |
| 页面 | `pages/SettingsView.vue` | GP 播放器设置组 |
| i18n | `i18n.ts` | `gp.*`、`settings.gp_*` 中英键 |

### 8.3 隐私与安全
- GP 文件仅在本地读取解析；AlphaTab 全部计算在本机 WebView 内完成。
- `read_file_bytes` 校验路径必须位于库 `Resources/GPFiles` 之下（canonicalize + 前缀判断），防止任意文件读取。

## 9. 验收标准
