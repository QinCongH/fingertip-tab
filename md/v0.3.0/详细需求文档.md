「看谱」与「设置谱」两个模块的需求范围、交互规则与验收口径，参考产品为 TabPilot（guitar.voicedance.online）。看谱模块覆盖谱面渲染、播放跟随、滚动与全屏查看；设置谱模块覆盖文件加载、音轨、速度、循环、节拍器、训练与统计等谱面相关设置。核心原则：曲谱文件全程本地解析，不上传、不存储、不分享。V1.0 优先交付 P0 功能（谱面渲染、播放控制、速度、音轨、循环、保存练习），Pro 能力（高倍速、训练器等）后置灰度；整体范围与优先级为方案建议，待评审确认。
1. 背景与目标
1.1 背景
吉他学习者普遍需要「看着谱子、跟着示范、反复练熟」的练习工具。现有 Guitar Pro 谱文件（.gp3/.gp4/.gp5/.gpx/.gp）包含六线谱、五线谱、音轨、小节等完整信息，但桌面端软件收费高、上手重，网页端工具又普遍需要上传文件、存在隐私顾虑。
TabPilot 以纯浏览器本地解析的方式解决上述问题：文件只在用户浏览器中打开，不上传、不存储、不分享，同时提供看谱（谱面渲染、播放跟随、自动滚动、全屏）与设置谱（速度、音轨、循环、节拍器、训练、统计）一整套练习能力。本文档以此为参考，定义同类产品中「看谱」「设置谱」两模块的需求。
1.2 目标
- 用户能零门槛打开本地 Guitar Pro 谱文件并完整查看谱面，播放时谱面自动跟随。
- 用户能按练习需求调整播放速度、音轨、循环片段、节拍器等设置，并保存练习过程。
- 全流程本地解析，隐私零负担；无网络依赖，断网可用。

2.2 术语定义
术语
定义
Guitar Pro 谱
Guitar Pro 软件生成的曲谱文件，常见扩展名 .gp3、.gp4、.gp5、.gpx、.gp，内含六线谱、五线谱、音轨、小节、演奏记号等结构化数据。
六线谱
吉他专用记谱法，六条线对应六根琴弦，线上数字表示品位，直观指示按弦位置。
五线谱
标准音乐记谱法，记录音高与时值，与六线谱对照可同时看到「弹哪里」与「弹什么音」。
音轨
曲谱中相互独立的演奏声部（如吉他、贝斯、鼓），可单独静音、独奏或调节音量声像。
小节
乐谱按拍号划分的基本节奏单位，练习中常以小节为单位设定循环片段。
循环小节
设定开始与结束小节，播放器反复播放该片段，用于片段精练。
预备拍
正式播放前先给若干拍节拍声，帮助演奏者找准速度起拍。

4. 「看谱」模块需求详设
4.1 谱面渲染与展示
谱面是看谱模块的核心，要求信息完整、跟随明确、长时间看谱不疲劳。
规则项
需求规则
渲染内容
同时渲染吉他六线谱与五线谱，上下对照；保留推弦、滑音、击勾弦、制音、泛音等演奏记号。
多音轨
多个音轨按上下顺序并列展示；每轨显示轨道名称，默认全部展开。
未加载态
主区域显示「等待曲谱文件，上传后这里会显示谱面」占位提示，无谱面内容。
渲染状态
加载过程中提示「正在渲染谱面」；渲染完成前不显示残缺内容。
4.2 播放跟随与进度
播放是看谱的驱动力，谱面必须与播放位置严格同步。
规则项
需求规则
当前小节标记
播放进行中，以高亮（红色）标记当前待演奏小节，随播放逐小节推进。
进度条
显示可拖动进度条与「已播时长/总时长」时间码（格式 mm:ss）；拖动进度条可跳转播放位置。
循环提示
启用循环小节后，进度条或谱面上标识循环片段范围，播放到结束小节自动跳回开始小节。
4.3 滚动模式
谱面随播放自动滚动，提供四种模式覆盖不同看谱习惯。
模式
需求规则
自动翻页
按页切换，当前页演奏完毕后整页滚动到下一页，保持页面完整。
连续跟随
谱面连续滚动，播放位置始终保持在可视区内。
平滑跟随
在连续跟随基础上加入平滑动画，减少跳动感，适合长曲目。
关闭滚动
谱面固定不动，用户手动滚动查看；切换模式后立即生效并提示。
4.4 全屏模式
- 点击「全屏模式」后隐藏左侧控制面板，谱面独占视口；顶部提供退出入口与快捷键。
- 全屏状态下播放、跟随、滚动等能力保持可用；退出后恢复原布局。
4.5 信息查看
看谱过程中用户需要确认「当前打开的是什么」，信息展示分文件信息与曲谱信息两级。
信息项
内容与规则
文件信息
文件名、文件大小、文件类型（Guitar Pro score）、加载状态；未加载时显示「未选择任何文件」。
曲谱信息
曲谱标题、音轨数、小节数；未解析前显示占位。
音轨列表
按编号与名称列出全部音轨（如 1·Pista 1、2·Pista 2），支持展开查看与操作入口。
4.6 规则与异常
看谱模块的异常场景集中在文件加载与渲染阶段，必须给出可行动的修复建议而非空白失败。
场景
处理规则
文件不可识别
提示「文件内容不是可识别的曲谱文件」，引导重新选择。
文件过小
提示「文件较小，继续加载」并继续解析，不阻断。
加载失败
给出三条修复建议：
- 使用 .gp3/.gp4/.gp5/.gpx/.gp 格式，而非 PDF、图片、网页或压缩包
- 标题或音轨名乱码时切换文字编码后重新选择
- 来自云盘或聊天软件的文件先保存到本地再选择
并提供「打开示例曲谱」「重新选择」「反馈格式问题」三个动作入口。
编码乱码
中文老谱默认支持 GBK 编码；乱码时提示切换编码并重新上传当前曲谱。
5. 「设置谱」模块需求详设
5.1 文件加载与格式
- 支持本地选择 .gp3、.gp4、.gp5、.gpx、.gp 五种 Guitar Pro 格式；提供「默认示例曲谱」便于无文件时体验。
- 加载全程本地解析：文件不上传、不存储、不分享，不生成公开链接；界面明示隐私说明。
- 加载流程状态机：未选择文件 → 等待解析 → 解析中 → 加载完成（就绪）/ 加载失败。
5.2 音轨设置
设置项
需求规则
全选音轨
一键启用全部音轨参与播放；再次点击可取消全选。
静音/独奏
单轨支持静音（Mute）与独奏（Solo），两者互斥关系按音轨惯例处理（独奏时其他音轨自动静音）。
音量与声像
每轨可独立调节音量百分比与声像（Pan），默认音量 100%、声像居中。
5.3 播放与速度
设置项
需求规则
播放控制
提供播放/暂停与停止；无文件加载时按钮置灰不可用。
速度调节
滑块连续调节 + 预设档位：0.75x、1x、1.25x；速度变更立即生效并提示。
Pro 倍速
1.5x、1.75x、2x、3x 属于 Pro 高级倍速：未开通时提供预览切换，并提示「正式付费开通后可长期使用」。
引擎兼容
当前播放引擎不支持变速时，给出明确提示，不静默失效。
5.4 循环小节
设置项
需求规则
起止设置
分别设置「开始小节」「结束小节」，开启后仅反复播放该片段；提供关闭与清除入口。
片段收藏
可将常用片段保存为收藏（记录起止小节与曲谱标题），下次加载同曲谱时一键使用。
边界校验
结束小节不得小于开始小节；超出曲谱总小节数时自动截断并提示。
5.5 节拍器与预备拍
- 节拍器可独立开启/关闭，与播放互不阻塞；提供音量调节。
- 预备拍（Count-in）开启后，播放前先给若干拍节拍声再进入正式播放。
- Tap Tempo：连续点击可测算目标 BPM，节拍器按测得速度运行并提示「已设置为 N BPM」。
5.6 渐进变速训练
面向「从慢到快逐步攻克」的练习方法：从起始速度开始循环，每轮结束后按步进升速，直至目标速度。
参数
需求规则
起始速度
训练起始倍速，需低于或等于目标速度。
目标速度
训练期望达到的倍速。
每轮升速
每轮结束后的倍速增量。
每轮时长
单轮循环的持续时间（秒）。
校验与反馈
参数无效时提示「请设置有效的起始速度、目标速度和每轮时长」；运行中显示当前倍速与轮次（如 1.2x·第 3 轮），完成或停止有明确提示。
5.8 保存练习与导出
- 保存练习：输入自定义文件名后将当前练习（曲谱、速度、音轨、循环等状态）保存到本机浏览器；练习列表可回看与继续，列表为空时显示空态。
- 导出 MIDI：将当前曲谱导出为标准 MIDI 文件，导出前确认文件名。
- 隐私约束：练习记录与收藏仅保存在本机浏览器，不上传云端。
