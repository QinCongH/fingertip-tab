# 🎨 指尖乐谱 - 前端初始化指南
**技术栈**：Vue 3 + TypeScript + Vite + Vuetify 3
---
## 1. 安装依赖
在项目根目录下执行以下命令，安装 Vuetify 及其必要的样式和图标依赖。
```bash
# 1. 安装 Vuetify 3
pnpm add vuetify
# 2. 安装样式预处理依赖 (Vuetify 强烈需要)
pnpm add -D sass sass-loader
# 3. 安装图标库
pnpm add @mdi/font material-design-icons-iconfont
```
---
## 2. 配置 Vite
Vuetify 需要在编译时解析 SCSS 变量，因此需要配置 `vite.config.ts` 的别名。
修改 `vite.config.ts`：
```typescript
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import { fileURLToPath, URL } from 'node:url'
// https://vitejs.dev/config/
export default defineConfig({
  plugins: [vue()],
  resolve: {
    alias: {
      '@': fileURLToPath(new URL('./src', import.meta.url)),
      // 配置 vuetify 的样式加载别名，这在开发中很重要
      'vuetify': 'vuetify'
    }
  }
})
```
---
## 3. 引入 Vuetify 插件
为了让 `main.ts` 保持整洁，我们创建一个单独的文件来配置 Vuetify。
新建文件 `src/plugins/vuetify.ts`：
```typescript
// src/plugins/vuetify.ts
import 'vuetify/styles'
import { createVuetify } from 'vuetify'
import * as components from 'vuetify/components'
import * as directives from 'vuetify/directives'
import { mdi } from 'vuetify/iconsets/mdi'
import '@mdi/font/css/materialdesignicons.css' // 确保图标样式被加载
// Vuetify 配置
const vuetify = createVuetify({
  components,
  directives,
  icons: {
    defaultSet: 'mdi', // 使用 MDI 图标集
  },
  theme: {
    defaultTheme: 'dark', // 默认深色模式，适合看谱
  },
})
export default vuetify
```
---
## 4. 挂载到主入口
修改 `src/main.ts`，引入 Vuetify 和路由。
```typescript
import { createApp } from 'vue'
import App from './App.vue'
import router from './router' // 假设你已经配置了 vue-router
import { createPinia } from 'pinia'
import vuetify from './plugins/vuetify' // 引入上面的配置
const app = createApp(App)
app.use(createPinia())
app.use(router)
app.use(vuetify) // 使用 Vuetify 插件
app.mount('#app')
```
---
## 5. 修改 App.vue (重要！)
Vuetify 3 要求必须在最外层包裹 `<v-app>` 标签，否则所有组件无法正常渲染。
修改 `src/App.vue`：
```vue
<template>
  <!-- Vuetify 必须的根组件 -->
  <v-app>
    <!-- 顶部导航栏 -->
    <v-app-bar color="primary" density="compact">
      <v-app-bar-title>指尖乐谱</v-app-bar-title>
      <v-spacer></v-spacer>
      <v-btn icon="mdi-cog" variant="text" @click="$router.push('/settings')"></v-btn>
    </v-app-bar>
    <!-- 侧边导航 (用于显示分组) -->
    <!-- <v-navigation-drawer>...</v-navigation-drawer> -->
    <!-- 主内容区域 (路由视图) -->
    <v-main>
      <router-view />
    </v-main>
  </v-app>
</template>
<script setup lang="ts">
// 这里的逻辑暂时留空
</script>
```

## 8. 常用 Vuetify 组件在“指尖乐谱”中的应用建议
Vuetify 的组件化非常适合你的需求：
*   **布局**：
    *   `<v-app-bar>`: 全屏时的悬浮工具栏。
    *   `<v-navigation-drawer>`: 左侧的分组列表。
    *   `<v-container>`: 居中显示吉他谱。
*   **交互**：
    *   `<v-btn>`: 翻页、播放按钮。
    *   `<v-slider>`: 调节自动滚动速度。
    *   `<v-switch>`: 开启/关闭 AI 动作捕获。
*   **数据展示**：
    *   `<v-card>`: 在“曲谱库”页面展示谱子封面和信息。
    *   `<v-list>`: 显示设置选项列表。
    *   `<v-dialog>`: 用于导入图片时的弹窗。
*   **反馈**：
    *   `<v-snackbar>`: 当导入成功或识别到摇头翻页时，弹出提示信息。
    *   `<v-overlay>`: 加载图片时的 Loading 遮罩。

## 第二部分：后端初始化
后端主要工作是引入数据库、图像处理、文件 IO 等核心库，并配置 Tauri 的权限。
### 1. 配置 Cargo 依赖
编辑 `src-tauri/Cargo.toml`，在 `[dependencies]` 下添加以下内容：
```toml
[dependencies]
# 核心依赖
tauri = { version = "2", features = ["devtools"] }
serde = { version = "1", features = ["derive"] }
serde_json = "1"
tokio = { version = "1", features = ["full"] }
# 数据库
sqlx = { version = "0.7", features = ["runtime-tokio-rustls", "sqlite", "chrono"] }
# 文件与图片处理
uuid = { version = "1", features = ["v4", "serde"] }
image = "0.24"
dirs = "5.0"
# 错误处理
anyhow = "1.0"
thiserror = "1.0"
# 日志
log = "0.4"
tauri-plugin-log = "2"
```
### 2. 后端目录结构
在 `src-tauri/src/` 目录下建立如下结构：
```text
src-tauri/src/
├── commands/       # Tauri 命令 (暴露给前端的接口)
│   ├── mod.rs
│   ├── tab.rs      # 导入、查询、删除谱子
│   └── settings.rs # 设置相关
├── db/             # 数据库模块
│   ├── mod.rs
│   ├── connection.rs # 数据库连接池
│   └── models.rs    # 数据库模型
├── utils/          # 工具类
│   ├── file.rs     # 文件移动、复制
│   └── image.rs    # 图片处理
├── error.rs        # 错误定义
├── lib.rs
└── main.rs
```
### 3. 基础代码编写
#### 3.1 错误处理 (`src-tauri/src/error.rs`)
统一错误类型，方便返回给前端。
```rust
use thiserror::Error;
#[derive(Error, Debug)]
pub enum AppError {
    #[error("Database error: {0}")]
    Db(#[from] sqlx::Error),
    #[error("IO error: {0}")]
    Io(#[from] std::io::Error),
    #[error("Image processing error: {0}")]
    Image(#[from] image::ImageError),
}
// 转换为 Tauri 能发送的结果
pub type Result<T> = std::result::Result<T, AppError>;
```
#### 3.2 数据库连接 (`src-tauri/src/db/connection.rs`)
初始化 SQLite 连接。
```rust
use sqlx::{SqlitePool, sqlite::SqliteConnectOptions};
use std::str::FromStr;
pub async fn init_db(db_path: &str) -> Result<sqlx::SqlitePool> {
    let options = SqliteConnectOptions::from_str(db_path)?
        .create_if_missing(true);
    let pool = SqlitePool::connect_with(options).await?;
    
    // 在这里运行 migrate 或者建表 SQL
    // sqlx::query_file!("../migrations/init.sql").execute(&pool).await?;
    
    Ok(pool)
}
```
#### 3.3 注册命令 (`src-tauri/src/commands/mod.rs`)
```rust
mod tab;
mod settings;
pub use tab::*;
pub use settings::*;
```
#### 3.4 更新 Main (`src-tauri/src/main.rs`)
```rust
#![cfg_attr(not(debug_assertions), windows_subsystem = "windows")]
mod commands;
mod db;
mod error;
mod utils;
use db::connection;
use error::Result;
// 获取数据库路径示例
fn get_db_path() -> String {
    // 简单示例，实际应结合配置文件
    "fingertip_tabs.db".to_string()
}
#[tauri::command]
fn greet(name: &str) -> String {
    format!("Hello, {}! You've been greeted from Rust!", name)
}
#[tokio::main]
async fn main() -> Result<()> {
    // 初始化数据库
    let db_path = get_db_path();
    let _pool = connection::init_db(&db_path).await?;
    tauri::Builder::default()
        .plugin(tauri_plugin_log::Builder::new().build())
        .invoke_handler(tauri::generate_handler![
            greet,
            commands::import_song, // 示例：注册你的命令
            commands::get_songs
        ])
        .run(tauri::generate_context!())
        .expect("error while running tauri application");
    Ok(())
}
```

## 第三部分：权限配置 (Tauri v2 重点)
在 Tauri v2 中，文件系统访问是默认受限的。你需要显式声明权限。
编辑 `src-tauri/capabilities/default.json`：
```json
{
  "identifier": "default",
  "description": "Default capabilities",
  "windows": ["main"],
  "permissions": [
    "core:default",
    "core:window:allow-start-dragging",
    "core:window:allow-maximize",
    "core:window:allow-minimize",
    "core:window:allow-close",
    "core:window:allow-hide",
    "core:window:allow-show",
    "core:window:allow-set-fullscreen",
    
    // 允许读取文件对话框
    "dialog:allow-open",
    
    // 允许读取文件内容 (用于加载图片)
    {
      "identifier": "allow-read-files",
      "allows": ["fs:read-file"]
    }
  ]
}
```
