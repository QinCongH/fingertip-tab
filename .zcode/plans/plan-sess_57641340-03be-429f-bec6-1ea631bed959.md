# 局域网共享与看谱交互优化方案

根据用户提出的三项明确需求：
1. **曲谱预览页面、局域网预览页面滚动速度 px 值，支持输入（不仅是滑块或加减按钮）**；
2. **局域网预览页面支持电视机遥控器交互（左右点击按键滚动/左右切换页面、返回按键、上下按键切换视图）**；
3. **首页局域网共享，支持通过 IP + 端口直接访问，无需 token**。

---

## 一、方案详细设计

### 1. 速度 px 值支持直接数字输入
#### A. 桌面端看谱页 (`src/pages/ViewerView.vue`)
- **当前现状**：底部悬浮工具栏在 `speedMode === 'px'` 模式下为 `<v-slider>` 加一个纯文本展示 `<span class="st-mono text-caption">{{ speedPx }} px/s</span>`。
- **改造方案**：
  - 将展示文本改造为（或并列增加）一个紧凑数字输入框 `<v-text-field v-model.number="speedPx" type="number" :min="1" :max="300" :step="0.5" density="compact" variant="underlined" suffix="px/s" max-width="110" hide-details @update:model-value="onSpeedChange" />`；
  - 滑块与数字输入框双向联动，用户既可以拖动滑块，也可以直接点击输入框键入具体的像素速度数值。

#### B. 局域网预览页 (`src-tauri/src/commands/share.rs`)
- **当前现状**：
  - 单曲预览页（`render_single_page`）与整库预览页（`render_library_mobile_page`）中，速度控制栏由 `-` 按钮、`<span class="speed-val">30 px/s</span>`、`+` 按钮组成，只能以 10px 步进点击。
- **改造方案**：
  - 将 `.speed-val` / `.img-speed-val` 改造为数字输入框 `<input type="number" id="speed-input" min="1" max="500" value="30" class="speed-input" /> px/s`；
  - 增加内联样式：深色背景、无边框或微下划线边框、等宽字体、居中或靠右显示；
  - 绑定 `input` / `change` 事件：当用户在手机或电视屏幕上键入数值时实时校验更新 `scrollSpeed = Math.max(1, Math.min(500, parseInt(val) || 30))`，并同步更新滚动驱动器；
  - 保留两旁的 `-` / `+` 微调按钮，点击时同步写回 `<input>`。

### 2. 局域网预览页面支持电视遥控器按键操作
主流 Android TV / 智能电视浏览器通过遥控器按键发送标准的 DOM 键盘事件（键名 `e.key` 及键码 `e.keyCode`）。
- **常见按键映射**：
  - **方向键**：
    - `ArrowLeft` / `21`（左）
    - `ArrowRight` / `22`（右）
    - `ArrowUp` / `19`（上）
    - `ArrowDown` / `20`（下）
  - **确定/选择键**：`Enter` / `Select` / `13` / `23`
  - **返回键**：`Escape` / `Back` / `BrowserBack` / `8` (Backspace) / `4` (Android KeyCode Back) / `10009` (Tizen/webOS)
  - **快进/快退/翻页键**：`MediaFastForward` / `MediaRewind` / `PageUp` / `PageDown`

#### 具体按键响应交互逻辑（在 `share.rs` 的全局 `window.addEventListener('keydown', ...)` 中统一实现）：
1. **左右按键（`ArrowLeft` / `ArrowRight`）**：
   - **大图查看弹窗激活时 (`lightbox.active`)**：左右键直接切换上下一张图片；
   - **多页横向自适应排版模式 (`mode-fit`)**：左右键平滑横向滚动容器（如 `scrollBy({ left: e.key === 'ArrowRight' ? 300 : -300, behavior: 'smooth' })`）；
   - **瀑布流纵向滚动模式 (`mode-scroll`)**：左右键亦可平滑微调或快速翻屏（`scrollBy({ top: e.key === 'ArrowRight' ? 500 : -500, behavior: 'smooth' })`）。
2. **上下按键（`ArrowUp` / `ArrowDown`）**：
   - 用户指定：“**上下按键切换视图**”。
   - 当没有聚焦在搜索输入框时，按 `ArrowUp` 或 `ArrowDown` 在 **自适应满高模式 (`fit`)** 与 **纵向滚动模式 (`scroll`)** 之间快速互相切换；或者切换全屏。切换时自动弹出简短气泡或更新视图状态。
3. **返回按键（`Escape` / `Back` / `Backspace` / `keyCode 4` / `keyCode 10009`）**：
   - 若当前处于大图全屏弹窗 (`lightbox.active`)：关闭弹窗，恢复页面滚动；
   - 若当前处于整库曲谱详情页面 (`detailView.style.display !== 'none'`)：返回曲谱列表视图 (`closeSongDetail()`)；
   - 若已在首页列表：不执行破坏性动作，保持在当前页。
4. **确定键（`Enter`）**：
   - 在滚动模式下可快捷启动 / 暂停自动滚动。

### 3. 首页局域网共享：支持 IP+端口 直接访问，无需 Token
#### A. 后端路由与访问认证改造 (`src-tauri/src/commands/share.rs`)
- **路由扩展**：
  - 新增根路由 `.route("/", get(root_page))` 以及无 token 路由：
    - `GET /` -> 访问首页整库（或者若当前是单曲共享则重定向/展示单曲，若整库共享则直接展示乐谱列表）；
    - `GET /api/songs` -> 无 token 访问乐谱列表；
    - `GET /api/song/:id` -> 无 token 根据 ID 获取曲谱详情；
    - `GET /api/file/:uuid/:ext` -> 无 token 加载乐谱资源文件。
  - 保留原有的带 token 路由兼容旧连接，但当会话开启时，无 token 路由直接有效。
- **校验逻辑**：
  - 只要共享服务运行中（`session().read().await.is_some()`），且请求发往上述无 token 路由，即认定为局域网合法访客，放行访问；
  - 文件读取仍严格进行 `uuid` 格式检查与 `ext` 扩展名白名单校验，杜绝目录穿越风险。
- **返回给前端的 ShareInfo URL 调整**：
  - 整库共享（`start_library_share`）：生成的 URL 直接为简洁的 `http://{ip}:{port}/`（无需拼接 `/s/{token}`）；
  - 单曲共享（`start_share`）：URL 可为 `http://{ip}:{port}/s/{token}` 或 `http://{ip}:{port}/?song={id}`，同时电视直接输入 `http://{ip}:{port}` 也能直达。
  - 在 `get_share_info` 与二维码生成中，全面更新为无 token 的简洁根链接。

#### B. 局域网页面前端逻辑调整 (`render_library_mobile_page` & `render_mobile_page`)
- 页面内的 AJAX 请求调整：
  - 当无 token 时，请求路径走 `/api/songs`、`/api/song/${s.id}`、`/api/file/${uuid}/${ext}`；
  - 彻底抹平必须在 URL 中维护 token 的限制，电视浏览器直接在地址栏手动键入 `192.168.x.x:17890` 即可秒开曲谱库。

## 二、验证计划
1. **编译后端**：运行 `cargo check --manifest-path src-tauri/Cargo.toml` 确保路由、状态机与 HTML 字符串无格式和类型错误。
2. **构建前端**：运行 `npm run build` 确保 Vue 组件、Vuetify 控件和 TypeScript 类型正常。
3. **功能验证**：
   - 验证 ViewerView 与局域网 web 页面的 px 速度输入框，可键入数字生效并双向同步；
   - 验证模拟电视按键（方向键、返回键、Backspace、ESC 等）在局域网页面正常驱动左右滚动/切页、上下切换视图、返回列表；
   - 验证无 token 直接通过 `http://<ip>:<port>/` 打开乐谱库，API 获取曲谱与图片资源正常加载。
